# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately to **security@ankra.io**. Do not open a public issue, pull request
or discussion for a suspected vulnerability.

Include the affected version (chart and image tag), a description of the issue and its impact, and steps to
reproduce. We acknowledge a report within three working days and keep you informed until it is resolved. We credit
reporters in the release notes unless you ask us not to.

## Supported versions

Security fixes are made on `main` and released as a new patch version. Only the latest release is supported.

## Scope

This repository covers the Ankra Cloud CSI driver, its container image and its Helm chart. Vulnerabilities in the Ankra Cloud API or
console are also reported to security@ankra.io.
